# Práctica 01 — Auditoría de Accesibilidad Web

## Objetivo

Identificar problemas de accesibilidad utilizando axe DevTools
y documentarlos mediante GitHub Issues.

## Sitios a auditar

- https://inaccessible.andrewwestley.co.uk/
- https://tu-aulatech.vercel.app

## Entrega

Cada pareja debe:

- Auditar ambos sitios con axe DevTools.
- Identificar 3 problemas de accesibilidad en cada sitio (6 en total).
- Analizar su impacto.
- Proponer una solución.
- Crear al menos 1 GitHub Issue por sitio (2 en total).

## Tiempo

- 30 minutos de práctica.
- 10 minutos de holgura.

## Formato de Issue

Título:

```
[A11Y] Descripción breve del problema
```

Descripción:

### Problema

¿Qué problema encontraste?

### Ubicación

¿Dónde ocurre?

### Impacto

¿Por qué afecta la accesibilidad?

### Solución propuesta

¿Cómo lo solucionarías?

### Evidencia

Adjuntar captura de axe DevTools.
