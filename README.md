# Práctica 01 — Auditoría de Accesibilidad Web

## Objetivo

Identificar problemas de accesibilidad utilizando axe DevTools
y documentarlos mediante GitHub Issues.

## Sitio a auditar

https://TU-AULATECH.vercel.app

## Entrega

Cada pareja debe:

- Identificar 3 problemas de accesibilidad.
- Analizar su impacto.
- Proponer una solución.
- Crear al menos 1 GitHub Issue.

## Formato de Issue

Título:

```
[A11Y] Descripción breve del problema
```

Descripción:

### Problema

¿Qué problema encontraste?

### Ubicación

¿Dónde ocurre?

### Impacto

¿Por qué afecta la accesibilidad?

### Solución propuesta

¿Cómo lo solucionarías?

### Evidencia

Adjuntar captura de axe DevTools.
